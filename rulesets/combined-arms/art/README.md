# 立体战线 · 美术约定

这套原创矢量素材使用装甲工业题材：深色底盘、冷灰金属、玩家队色装甲、青色仪表与推进器、少量琥珀色警示条。没有外部字体、贴图、商标或网络依赖。

所有单位、建筑和矿点都有独立 SVG。步枪兵以头盔、肩甲和步枪识别；工人使用工程座舱、机械臂；坦克以履带和长炮管识别，架炮展开支撑脚；机甲有反关节腿和导弹巢；战舰采用双引擎和聚能炮。埋设地雷只露出低矮的探测盖板。医疗兵背白色医疗箱、胸前红十字、手里的治疗枪带一团光；采矿机是带铲斗和信号灯的小履带车；科技挂件顶上有探测碟，反应挂件是两根发光的反应柱；研究所正面一排窗、屋顶数据屏，军械库是厚墙和卷帘门，聚变核心是支架托着的能量球。建筑起飞时由平台抬高、画影子和推进火光，不需要另画素材。

`currentColor` 由回放播放器替换成玩家颜色。单位坐标以一格为 1，建筑和资源坐标以整个占地为 1；SVG 的 `viewBox` 包含炮管、天线等突出部分。保持大轮廓和队色区域清晰，细节在缩小后可以自然消失。

`types.ts` 的 `look.art.weapon` 指定武器特效，`look.art.motion` 指定机械动作。状态的素材覆盖与普通素材一起嵌入回放，网页和视频共用渲染。后坐力、弹道、引擎焰、工具火花和爆炸由 Canvas 绘制，以保持确定性并适应不同分辨率。武器效果仅作表现，数值和结算使用原有规则。
